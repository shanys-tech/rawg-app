# RAWG App

Application web React permettant d'explorer la base de données de jeux vidéo RAWG.

---

## Description

Application frontend qui consomme l'API publique RAWG.io. Elle permet de rechercher des jeux, filtrer par plateforme ou store, consulter les détails d'un jeu et gérer une liste de favoris persistante.

---

## Fonctionnalités

- Affichage de la liste des jeux
- Filtres par plateforme (PC, Xbox, PlayStation...) et par store (Steam, Epic Games...)
- Tri par toutes les options disponibles sur l'API
- Pagination ou infinite scroll
- Page de détail d'un jeu : nom, description, trailer, plateformes, achievements
- Liste des jeux d'un éditeur
- Favoris persistants entre les sessions
- Page 404 avec redirection

---

## Technologies

- Framework : React
- Requêtes HTTP : Axios
- Gestion d'état : React Context
- Styles : CSS Modules
- Notifications : react-toastify
- Tests : Cypress
